## Использование

На данном этапе в виджете реализованы следующие функции:

- маскировка номера банковской карты
- маскировка номера банковского счёта
- улучшенная версия функции, способная обрабатывать информацию как о картах, так и о счетах
- получение даты в необходимом формате
- фильтрация по ключу последних операций клиента
- фильтрация по дате последних операций клиента
